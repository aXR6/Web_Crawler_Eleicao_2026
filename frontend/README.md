# Tela web — Eleições 2026

Painel em Next.js que exibe os resultados do [buscador.sh](../buscador.sh).
Como executar e o que a tela faz: veja a seção **Implementação: tela web** no [README principal](../README.md#implementação-tela-web).

```bash
npm install
npm run dev      # http://localhost:3000
```

O servidor executa `../buscador.sh`. Para usar outro caminho, defina `BUSCADOR_SH=/caminho/para/buscador.sh`.
